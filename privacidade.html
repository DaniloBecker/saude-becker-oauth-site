Política de Privacidade — Saúde Becker OAuthReader

Última atualização: 16 de outubro de 2026.

1. Finalidade

O Saúde Becker OAuthReader é uma ferramenta privada de uso pessoal, utilizada exclusivamente para automação e manutenção do projeto Saúde Becker.

2. Dados acessados pelo Google OAuth

A ferramenta utiliza Google OAuth para identificar a conta autorizada e acessar, em modo somente leitura, projetos específicos do Google Apps Script.

Os escopos utilizados são:

  • openid — identificação da conta autorizada;
  • email — confirmação do endereço de e-mail autorizado;
  • script.projects.readonly — leitura de projetos do Google Apps Script.

3. Armazenamento de credenciais

O refresh token OAuth é armazenado localmente no computador autorizado, protegido pelo Windows Data Protection API (DPAPI) e vinculado ao usuário do Windows.

Access tokens temporários não são armazenados de forma persistente.

4. Uso dos dados

Os dados obtidos pelas APIs do Google são utilizados exclusivamente para funções autorizadas do projeto Saúde Becker.

Os dados não são vendidos, utilizados para publicidade ou compartilhados com terceiros para fins comerciais.

5. Compartilhamento

O OAuthReader é destinado exclusivamente ao proprietário do projeto. Credenciais OAuth e tokens não são disponibilizados publicamente.

6. Retenção e segurança

Credenciais persistentes são mantidas somente enquanto forem necessárias para a automação autorizada e podem ser revogadas pelo proprietário. Medidas de segurança incluem criptografia local, validação de identidade, validação de escopos e comportamento fail-closed.

7. Revogação de acesso

O proprietário pode revogar o acesso do aplicativo a qualquer momento através das configurações de segurança da Conta Google.
